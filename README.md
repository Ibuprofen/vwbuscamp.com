vwbuscamp.com
==========

Hosted for Burning Man's VW Bus Camp theme camp.

[vwbuscamp.com](http://vwbuscamp.com/)

Plain static HTML, no build step. The header, nav, sidebar and footer are
copied into each page, so the yearly update (camp address in the sidebar,
copyright year in the footer) is a find-and-replace across the `.html` files.
